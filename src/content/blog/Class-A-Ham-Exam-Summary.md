# **个人A类业余无线电考试总结**

QQ:755848971 email:kndxhz@163.com

操作证：驾照；核验：验车；电台执照+呼号：车牌

法规题：

按照自己的常识选就行。最高法有军委就选军委，没有就选工业和信息化部。

不要选任何“**体委**”、“**业余无线电协会**”、“**会员**”之类

处罚：**三万以下**、**一千以上**、**五千以下**（按顺序匹配，除了管制）

法则：**刑法**、**民法典**

用法题：

不要选任何“娱乐”、“车辆”、“公益”的选项。

业余无线电并不是专门为了抢灾设计，抢灾只不过是附加

设置电台年龄**18**，使用年龄不受限制（有操作证）

任何不是常规的常见收发信电台都是**特殊**

换地区的电台，选**最长的选项**

中继台是特殊，必要时**一键终止发射**

在业余无线电的世界里，**一切都是平等的**，不存在优先

任何设备都要**核准且符合标准**

续期期限：**一个月前**，任何更改都要报备

吊销去找核发的机构

沟通题：

使用**公认的短语**，实验需要尽可能公开

任何人都要确保自己的设备**正常运作**

不得收取业余之外的内容，不小心收到了不得公开，不得发送任何无关信号。

业余无线电**不涉及任何_商业内容、公益内容、公众内容_**

专业题：

日志内容：**时间**（TIME、DATE）、**频率**（FREQ）、**模式**（MODE）、**对方呼号**（CALL）、**双方信号**（RST）

必须收发：**本台呼号**、**对方呼号**、**信号报告**

呼号必须**完整**清晰的报出，且至少**每十分钟报出一次**，异地需加**“/”**。**不能**重新分配呼号

发射之前需要**守听、询问**，测试应**避开热点**，应保持空闲

客席使用**自己的异地**或者**做客的呼号**

在外地、不使用他人电台为**异地发射**

分类：**主要业务**、**次要业务**，不得干扰主要业务

杂散也是发射、无线电是**电磁波**

管制是**双特定**、**强制性**、**技术阻断**，单位是**最长的**，违反**公安处罚**

由国家将某个特定的频带列入频率划分表：**划分**

将无线电频率或频道规定由一个或多个部门：**分配**

将无线电频率或频道批准给具体的业余无线电台在规定条件下使用：**指配**

430-440是**次要业务**，避免占用144的**头和中**，避免占用431的**头和中**

我国是**UTC+8，比国际快（后一天）**
